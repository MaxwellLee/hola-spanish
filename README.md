# Hola · 慢慢学西语

为零基础业余学习设计的西班牙语教材阅读网页。包含《现代西班牙语》学生用书 1 的全部 305 个 PDF 扫描页面、OCR 点读文字、划词翻译、生词收藏与复习，以及可选的 Kimi 学习伙伴。

## 使用

- [打开学习网页](https://maxwelllee.github.io/hola-spanish/)
- 轻点西语单词或选中句子，在当前页查看中文。内置词表优先，其余通过 MyMemory 的无密钥接口翻译；网络或额度问题会显示失败提示，不会编造释义。
- 点击喇叭听西语，支持实际可用声音选择、试听、0.1～1.2 倍调速与停止；语速会保存在当前浏览器，Luna 朗读也使用同一设置。声音及实际慢速效果取决于设备/浏览器，优先 es-ES；不保证每台设备均有男女声，也不是教材原配录音。
- 原书、文字与对照三种视图。原书扫描完整保留原有颜色和分辨率；HTML 文字可放大，但扫描的缺失细节不会凭空恢复。
- 生词收藏、阅读标记、每日小任务保存在当前浏览器。生词本可导出、导入备份；不同设备之间不自动同步。
- 生词复习按 1、3、7、14 天安排；“还不熟”会在 10 分钟后再次到期。每天自行选择合适的学习量。
- iPhone 使用单栏、底部播放栏和底部翻译卡片；iPad 支持横竖屏，窄屏对照视图上下排列。

## 内容质量边界

完整扫描页是核对依据。全书 OCR 尚未逐页人工校订，尤其复杂表格、中文、西语重音、音标及图片中的文字可能有误。PDF 第 17 页课文对话已对照原页校订，其余不得称为“全书精校”。语音合成不能保证正确示范孤立音标、拼读或字母组合。

## AI 学习伙伴

支持情景对话、随文解释、温和纠错和本课小挑战。未连接后端时明确显示未连接状态；不会用预设内容冒充模型回答。只提供文本反馈，不测量发音准确率。

「语音对话」支持西班牙语或中文输入：点一次后持续保持开启，识别到最终文字后等待约 1.2 秒停顿再发送（浏览器自行结束识别时可能更早）。Luna 回答后朗读西语部分；回复只有中文时使用中文语音，不再将没有西语误报为朗读失败。读完继续收音，没说话或浏览器正常结束识别时自动重新等待，不发送空消息。偶发朗读失败会保留文字、提示失败并继续听；权限、网络或 AI 请求失败仍会停止并说明原因。播放时可点「打断，轮到我」停止朗读并恢复收音。语音转写由浏览器/系统的语音服务完成，Kimi 只接收文字；当前仍是轮流收音和播放，尚不支持边播放边识别、开口自动打断。

点击「结束语音」、收起伙伴、切到后台或开始教材朗读，都会停止语音对话。西语音色和全部朗读语速沿用教材设置，中文使用设备可用的中文声音。浏览器不支持时可改用键盘听写。真实 iPhone/iPad 麦克风、自动播放权限与语音质量仍需在设备上确认。

AI 默认后端已切换到腾讯云广州 SCF，网页已预填 HTTPS 服务地址。2026-10-17 从当前电脑不经系统代理完成真实对话测试。按账户持有人的选择连接 Kimi Code 会员接口，使用会员额度，受套餐额度与频率限制；不自动回退到开放平台按量付费。会员密钥配置在腾讯云环境变量中，网页使用独立学习口令。详见 [后端配置说明](backend/README.md)。

Luna 连接设置默认勾选“记住这台设备”：每个设备、每个浏览器首次输入学习口令并保存后，刷新和重新打开都会恢复连接配置，不需要每天输入。可取消勾选后保存以仅在本次页面使用，也可点击“退出并清除口令”。学习口令与后端地址一起保存在当前浏览器；Kimi API 密钥仍只在后端。清除网站数据、无痕模式或浏览器限制可能导致需要重填；对话记录仍不持久保存。

可通过 [腾讯云 SCF 上传包与部署说明](backend/TENCENT.md) 重建后端。默认每个实例保留 5 秒请求间隔和每日 100 次计数，但实例重启或扩容会重新计数，不能当作严格的全账户每日上限或费用预算。旧 Cloudflare 部署仍保留，但网页不会自动回退到它。浏览器保存的原 Cloudflare 地址会自动迁移到腾讯云，自定义地址保持不变。

Kimi Code 与开放平台的密钥、服务地址、模型名和额度不互通。当前会员接口以真实应用标识 `HolaSpanishStudy/1.0` 请求，不伪装其他客户端。若日后手动切换到开放平台，需一起更换这些配置，并确认独立计费；密钥只填写在后端配置中，不放入网页源码或提交到 GitHub。

## 本地预览与验证

从项目根目录执行：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

打开 `http://127.0.0.1:8765/`。不推荐直接用 `file://` 打开，因为浏览器会限制教材 JSON 读取。

```sh
node tools/check-core.mjs
node tools/check-backend.mjs
node tools/check-speech.mjs
```

安装开发依赖后，保持预览服务运行，执行 `npm run test:ui`。UI 检查采用 Chrome 的手机/iPad 设备尺寸模拟，不能替代真实 Safari 的选词、播放和键盘测试。真实 Kimi 响应需配置账户后另行验证。

`node tools/check-companion-ui.cjs` 检查侧栏在五种视口下的空间、语音按钮、模拟转写/播放、权限失败与收起清理。`tools/check-speech.mjs` 使用模拟识别器，不代表真实麦克风服务已通过验证。

## 结构与重建

- `site/`：发布内容，无构建步骤。教材按页加载，首页无需下载整本书。
- `backend/`：可选 AI 后端，校验来源、口令、消息长度与持久用量上限。
- `tools/`：扫描提取、双语 OCR、网页数据生成和检查脚本。
- `.github/workflows/pages.yml`：从 `main` 部署 `site/` 到 GitHub Pages。

重建需要用户自己的源 PDF：先执行 `python tools/extract_book.py <source.pdf>`，将西班牙语和简体中文 Tesseract 模型放入 `tmp/tessdata/`，运行 `node tools/ocr_book.cjs`，再运行 `python tools/build_book.py`。原始中间文件不提交。

无分析追踪脚本。在线翻译会将所选文字发到 MyMemory；AI 仅在主动发送时将当前页片段及有限对话发到配置的 Kimi 后端。
